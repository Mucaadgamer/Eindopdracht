# Eindopdracht CRUD Systeem

## Over het project

Voor mijn eindopdracht heb ik een CRUD systeem ontwikkeld voor een bedrijf. Met dit systeem kunnen gegevens worden toegevoegd, bekeken, aangepast en verwijderd (Create, Read, Update, Delete).

Het doel van het project was om een werkende webapplicatie te bouwen waarmee een bedrijf zijn gegevens overzichtelijk kan beheren.

## Functionaliteiten

Het systeem bevat de volgende functies:

* Gegevens toevoegen (Create)
* Gegevens bekijken (Read)
* Gegevens aanpassen (Update)
* Gegevens verwijderen (Delete)
* Overzichtelijke interface

## Gebruikte technieken

Tijdens deze opdracht heb ik gewerkt met:

* PHP
* HTML
* CSS
* JavaScript
* Git
* GitHub

## Wat ik heb geleerd

Tijdens het maken van deze eindopdracht heb ik geleerd hoe ik een volledig werkend CRUD systeem kan bouwen. Ik heb gewerkt met PHP voor de logica en HTML en CSS voor de structuur en vormgeving van de website. Met JavaScript heb ik interactieve onderdelen toegevoegd.

Daarnaast heb ik geleerd hoe ik Git kan gebruiken om mijn werk bij te houden en hoe ik GitHub kan gebruiken om mijn project op te slaan en te delen. Door deze opdracht heb ik beter geleerd hoe een webapplicatie wordt opgebouwd en hoe ik problemen kan oplossen tijdens het programmeren.
